---

## Reporting a Vulnerability

We take the security of this tool seriously. If you believe you have discovered a security vulnerability or unsafe conduct within this script, please follow the procedure below:

### How to Report
- **Do NOT** open a public issue on GitHub for security vulnerabilities.
- Send a detailed email directly to: **amrkhalid.dev@gmail.com** (or contact via GitHub Profile).
- Include the following details in your report:
  - Script version and environment (Windows 10/11 version, PowerShell version).
  - Steps to reproduce the issue or proof-of-concept (PoC).
  - Potential impact of the vulnerability.

---

## Response Process

1. **Acknowledgement:** You will receive an initial response acknowledging your report within **48 hours**.
2. **Assessment:** We will review the submission, investigate the risk, and determine the fix required.
3. **Patch & Disclosure:** A patch will be pushed to the `main` branch, and a fixed release will be published. Public credit will be attributed to the reporter (if desired).

Thank you for helping keep this project safe!
